# 视频计划 / Video plan

官网允许剪辑、配音和字幕，但**必须有软件真实运行的画面**。不要只用静帧，也不要把演示替身配成「这是 Lux3D 刚生成的」。

建议总长 70–90 秒。竖屏和横屏都可以，横屏更适合评委看清房间。下面时间是建议，不是必须卡点。

## 拍摄清单

| 时间 | 画面（必须是正在运行的软件） | 旁白（中文，可改） |
| --- | --- | --- |
| 0–8 秒 | 门厅。点「从这间寝室开始」。 | 六平米，也要有自己的光。这是宿舍改造家。 |
| 8–20 秒 | 空的入住卡，再点「吉林，四人，南窗」。让人看见预算、南向、暖木。 | 先把约束说清楚：四人上床下桌，预算八百，窗朝南，人在吉林。 |
| 20–28 秒 | 点一次非法预算，让红色错误出现，再改回 800。 | 说不通的预算不会被悄悄收成一间房。 |
| 28–45 秒 | 走进房间。缓慢环视。牌子「演示替身 / 不是 Lux3D」要进画。平面图可以闪一下。 | 这间能走进去。衣柜让开了窗，过道留了九十厘米。你现在看见的家具是演示替身，还不是 Lux3D。 |
| 45–55 秒 | 把时间滑到「晚自习」。灯变暖，窗外变暗。 | 十一月下午四点天就暗了。所以先买灯，不先买地毯。 |
| 55–65 秒 | 打开 Lux3D 面板，展示一条真实提示词，并点开「官方文档示例」让任务号和来源说明入画。 | 这些提示词会交给 Aholo Lux3D 做床、椅子和灯。文档里的示例响应，我们没有当成自己的模型。 |
| 65–75 秒 | 「拍一套」，滑过讨论图，点「复制讨论稿」。 | 开室友会之前，先把门口、窗边和每张床留下。 |
| 75–90 秒 | **你的 Lux3D 账号画面**：同一条提示词提交、等待、得到模型，再贴回房间或在本机密钥模式下看到「Lux3D #任务号」。 | 积分花在官方生成上。模型回到这间寝室，牌子就不再只写替身。 |

若暂时没有积分，就停在 75 秒，旁白改成：「密钥和积分在我自己的 Aholo 账号里。演示先把请求和替身分开，生成结果会补在报告里。」不要补一段假装的成功动画。

## 英文旁白（可选，短一些）

“Dorm Remix walks a Chinese dorm before the roommate meeting. The sign says stand-in, because Lux3D has not been called yet. The prompts on screen are what we send. The sample task ids are from the official docs, not from this room. Lamps come before rugs, because a Jilin afternoon is already dark.”

若有真实生成，加一句：“This next shot is the live Lux3D task.”

## 必须入画的诚实信息

- 房间里的「演示替身 / 不是 Lux3D」，或顶栏那句「本地程序化替身」。
- Lux3D 面板里的提示词。
- 若展示文档示例，字幕或界面要能看出那是官方示例。
- 真实任务号只在你真的提交之后出现。

## 不需要的东西

- 不要配没有授权的热门音乐。环境声或旁白就够。
- 不要录登录密码或 API key。
- 不要用去年的赛制口播。口播里的截止时间是 2026-11-19 19:00 北京时间。

## 导出

1080p 即可。文件名建议 `dorm-remix-demo.mp4`。上传到赛事表单的视频栏，或传到可公开访问的位置后把链接填进报告第 10 页。
